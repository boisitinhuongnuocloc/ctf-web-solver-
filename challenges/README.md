# Challenges Directory

Đặt các thư mục hoặc file `.zip` bài thi CTF Web vào đây.

Ví dụ:
- `challenges/pico_cookies/`
- `challenges/cscv_lfi/`
- `challenges/web_gauntlet.zip`

Mỗi thư mục có thể chứa thêm:
- `target.txt`: Điền link instance của bài thi (ví dụ: `http://saturn.picoctf.net:54321`)
- `flag_format.txt`: Điền format flag (ví dụ: `picoCTF` hoặc `cscv2026`)
